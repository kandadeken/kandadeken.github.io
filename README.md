# Preview of thecementpeople.com

A review copy of The Cement People website, for trying changes on real
phones and computers before they go live.

- Currently showing: the `phase-hero-integration` branch of
  `kandadeken/the-cement-people-website` (new hero), built with
  `npm run build`, then `node scripts/make-preview.mjs` (see `web/README.md`).
- Not for customers and not for search engines: every page is marked
  noindex and robots.txt blocks all crawlers.
- Contains no CNAME file, so it can never take over thecementpeople.com.
- Prices, products and contact details are the real ones; an estimate sent
  on WhatsApp from here goes to the real business number.
